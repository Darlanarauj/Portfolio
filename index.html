01 / SOBRE MIM

Curiosidade como método de trabalho

Sou o Darlan — formado em Análise e Desenvolvimento de Sistemas pela GRAN Faculdade. Gosto de entender como as coisas funcionam por dentro e, principalmente, como elas podem funcionar melhor.

Meu trabalho transita entre desenvolvimento web, automação de processos e análise de dados, sempre buscando a solução mais simples e eficiente para o problema real — seja um script que economiza horas de trabalho manual, seja uma interface pensada para quem vai usá-la todos os dias.

Este espaço reúne projetos pessoais e acadêmicos que refletem essa jornada: da automação de estações de trabalho a painéis de dados, passando por experimentos com voz, sistemas embarcados e web.

EI-Controle — Assistente de voz pt-BR ↗

Assistente de voz em português para Windows, construído em Python. Escuta comandos falados e executa ações diretamente no sistema operacional — do controle de tela à automação de rotinas de trabalho.

  • Blackout multi-monitor por comando de voz ("apagar tela" / "acender")
  • Bloqueio automático da estação de trabalho
  • Integração com Digifort e Outlook
  • Atalhos de sites e de teclado configuráveis
  • Interface gráfica em Tkinter com log de comandos
  • Configuração segura via variáveis de ambiente, sem dados sensíveis no código
